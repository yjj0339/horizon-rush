# 疾驰地平线 · 都会嘉年华（Horizon Rush）

**在线游玩：https://yjj0339.github.io/horizon-rush/**（手机扫码即玩，见 `qr-live.png`）

致敬《极限竞速：地平线》的开放世界 3D 自由赛车网页游戏。
跑车模型由 **Blender 5.2 无头建模**（`tools/make_car.py`）程序化生成并导出 GLB，
世界渲染基于 **Three.js r170**（PBR 车漆 / HDR 天空 / 泛光 / MSAA 后期）。

## 玩法

开放世界自由狂飙，没有固定赛道：

- **650m 半径都会城市** + **4 车道环线高速**（带护栏与缺口出入口）
- **海岸公路 / 沙滩**（往海里开会被浪推回）
- **嘉年华会场**：旋转摩天轮、彩色帐篷、热气球
- **郊野田园**：麦田色块、旋转风力发电机、海面波纹流动
- **6 座飞跃坡道** + 12 块空中/地面**奖励牌** + 4 处**测速点**
- 技巧积分：漂移 / 飞跃 / 擦身而过 / 撞奖励牌 / 测速；最佳纪录自动存档
- AI 交通流：环线、海岸路、东大道、城市街区都有车
- 支持 **Xbox 手柄**（RT 油门 / LT 刹车 / 摇杆转向 / A 手刹 / X 氮气 / Y 视角）

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` / `S` | 油门 / 刹车·倒车 |
| `A` / `D` | 转向 |
| `空格` | 手刹漂移（积攒氮气） |
| `Shift` | 氮气加速 |
| `C` | 切换视角（追尾 / 引擎盖 / 远景） |
| `R` | 复位回最近道路 |
| `G` | 霓虹底盘灯 |
| `M` | 静音，`Esc` 暂停 |

手机横竖屏均可，自动出现触屏按键。

## 本地运行

```bash
node serve.js        # http://localhost:8791/
```

## 技术要点

- `tools/make_car.py`：Blender 无头 Python 建模（放样车身 / 玻璃座舱 / 轮毂刹车卡钳 / 尾翼灯光），导出 `assets/car.glb`、`assets/sedan.glb`
- 车漆：清漆 PBR + PMREM(HDR 天空) 环境反射
- 后期：MSAA×4 + UnrealBloom + 速度感应色差/暗角，ACES 色调映射
- 物理：街机漂移模型（手刹减抓地 + 氮气回充）、坡道抛射飞跃
- 世界：程序化地形丘陵 / 海滩 / 远山，全部资产零外部依赖

## 取景参数

`?auto=1` 跳过菜单；`&pos=fest|city|plaza|highway|coast|beach|wheel|ramp` 指定出生点；
`&touch=1` 强制触屏按键；`&noui=1` 隐藏 HUD。
